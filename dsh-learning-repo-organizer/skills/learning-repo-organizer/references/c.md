# C 语言仓库

## 编译

```bash
gcc -std=c11 -Wall -Wextra -o <程序名>.exe <程序名>.c -lm
```

`-lm` 用于数学库（如 `sqrt`），不加会在链接时报错。`.exe` 是编译产物，不放进仓库。

## 测试

- 每个程序的 `tests/<程序名>.txt` 写一个或多个用例，用例之间用 `---` 分隔。
- 运行器会编译 `.c` 文件，用 `-Wall -Wextra` 检查，然后比对输出。
- 运行 `python run_tests.py`（全部）或 `python run_tests.py 261023`（某一天）。

不适合自动测试的 C 程序：

- 使用 `rand()` 或 `time()` 的程序，输出每次都不同（例如猜数字游戏）。
- 输入不固定、需要人工判断结果的程序。

## 常见问题要检查

- `scanf` 没有检查返回值，或者 `%s` 没有限制长度（可能溢出）。
- 用 `==` 比较浮点数，结果可能不准确。
- `int` 在阶乘、求和较大时会溢出（例如 `factorial(13)`）。
- 函数声明为有返回值却没有 `return`。
- `main` 结尾缺少 `return 0`（C99 之后不影响编译，但最好写上）。

## 文件名

- 避免 `01.c`、`03wtf.c` 这种看不出内容的名字，改成描述功能的名字，比如 `max_of_three.c`。
- 避免 `%`、空格等特殊字符。
